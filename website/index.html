4 Flexible API Styles

Choose the style that fits your workflow

1. Namespace API

Organized by category

import { str } from '@oxog/strkit';

str.case.camel('hello world');     // 'helloWorld'
str.validate.email('a@b.com');     // true
str.similarity.levenshtein('a','b'); // 1

2. Direct Import

Tree-shakeable

import { camelCase, isEmail } from '@oxog/strkit';

camelCase('hello world');  // 'helloWorld'
isEmail('test@test.com');  // true

3. Chainable API

Fluent & immutable

import { S } from '@oxog/strkit';

S('  Hello World  ')
  .trim()
  .camelCase()
  .truncate(8)
  .value;  // 'helloW...'

4. Prototype Extension

Native string methods

import '@oxog/strkit/extend';

'hello world'.camelCase();   // 'helloWorld'
'test@test.com'.isEmail();   // true

14 Locales Supported

Proper case conversion and transliteration for multiple languages

import { str, setLocale } from '@oxog/strkit';

// Turkish locale - proper i/I handling
str.case.upper('istanbul', { locale: 'tr' });  // 'İSTANBUL'
str.case.lower('ISTANBUL', { locale: 'tr' });  // 'ıstanbul'

// Transliteration
str.sanitize.transliterate('Привет', 'ru');    // 'Privet'
str.sanitize.transliterate('你好', 'zh');       // 'ni hao'

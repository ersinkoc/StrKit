Search

10 methods for searching within strings.

Basic Search

str.search.contains('hello world', 'world');     // true
str.search.contains('hello world', 'World', {
  caseSensitive: false
}); // true

str.search.startsWith('hello world', 'hello');   // true
str.search.endsWith('hello world', 'world');     // true

Index & Position

str.search.indexOf('hello world', 'o');          // 4
str.search.lastIndexOf('hello world', 'o');      // 7
str.search.indexOf('hello world', 'o', { fromIndex: 5 }); // 7

str.search.positions('abracadabra', 'a');        // [0, 3, 5, 7, 10]
str.search.countOccurrences('abracadabra', 'a'); // 5

Regex Match

str.search.match('hello 123 world', /\d+/);      // '123'
str.search.matchAll('hello 123 world 456', /\d+/g);
// ['123', '456']

All Methods

contains - Check if contains
startsWith - Check start
endsWith - Check end
indexOf - First occurrence index
lastIndexOf - Last occurrence index
countOccurrences - Count matches
positions - All positions
match - First regex match
matchAll - All regex matches

Sanitization

str.sanitize namespace

13 methods for cleaning, escaping, and sanitizing strings. Protect against XSS and create URL-safe content.

Quick Import:

import { str } from '@oxog/strkit';
// Use: str.sanitize.escapeHtml('<script>')

Escaping

str.sanitize

Escape special characters for security and formatting.

Example
// Escape special characters
str.sanitize.escape('Hello "World"');         // 'Hello \"World\"'
str.sanitize.unescape('Hello \\"World\\"');   // 'Hello "World"'

// HTML entities (XSS protection)
str.sanitize.escapeHtml('<script>alert("xss")</script>');
// '&lt;script&gt;alert(&quot;xss&quot;)&lt;/script&gt;'

str.sanitize.unescapeHtml('&lt;div&gt;');    // '<div>'

// Escape regex special characters
str.sanitize.escapeRegex('a.b*c?');           // 'a\\.b\\*c\\?'

Slugify

str.sanitize

Create URL-safe slugs with locale support.

Example
// Basic slugify
str.sanitize.slugify('Hello World!');         // 'hello-world'
str.sanitize.slugify('Blog Post Title');       // 'blog-post-title'

// With locale support (Turkish)
str.sanitize.slugify('Turkce Baslik', { locale: 'tr' }); // 'turkce-baslik'

// Safe filename
str.sanitize.filename('file:name?.txt');      // 'file-name-.txt'

// Chainable API
S('Hello World!').slugify().value;            // 'hello-world'

HTML & Transliteration

str.sanitize

Strip HTML tags and transliterate non-Latin scripts.

Example
// Strip HTML tags
str.sanitize.stripHtml('<p>Hello <b>World</b></p>'); // 'Hello World'

// Remove diacritics (accents)
str.sanitize.latinise('Hallo World');         // 'Hello World'
str.sanitize.latinise('cafe');              // 'cafe'

// Transliterate non-Latin scripts
str.sanitize.transliterate('Privet', 'ru');   // 'Privet'
str.sanitize.transliterate('nihao', 'zh');     // 'ni hao'

// Normalize whitespace
str.sanitize.clean('  hello   world  ');     // 'hello world'

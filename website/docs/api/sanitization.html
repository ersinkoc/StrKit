Sanitization

13 methods for cleaning and escaping strings.

Escaping

str.sanitize.escape('Hello "World"');         // 'Hello \"World\"'
str.sanitize.unescape('Hello \\"World\\"');   // 'Hello "World"'
str.sanitize.escapeHtml('<script>alert("xss")</script>');
// '&lt;script&gt;alert(&quot;xss&quot;)&lt;/script&gt;'
str.sanitize.unescapeHtml('&lt;div&gt;');    // '<div>'
str.sanitize.escapeRegex('a.b*c?');           // 'a\\.b\\*c\\?'

Slugify

str.sanitize.slugify('Hello World!');         // 'hello-world'
str.sanitize.slugify('Türkçe Başlık', { locale: 'tr' }); // 'turkce-baslik'

// Chainable
S('Hello World!').slugify().value;            // 'hello-world'

HTML & Transliteration

str.sanitize.stripHtml('<p>Hello <b>World</b></p>'); // 'Hello World'
str.sanitize.latinise('Héllo Wörld');         // 'Hello World'
str.sanitize.transliterate('Привет', 'ru');   // 'Privet'
str.sanitize.transliterate('你好', 'zh');     // 'ni hao'

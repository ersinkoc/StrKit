Case Conversion

str.case namespace

14 methods for transforming string case with full locale support for proper internationalization.

Quick Import:

import { str } from '@oxog/strkit';
// Use: str.case.camel('hello world')

// Or direct import:
import { camelCase, kebabCase } from '@oxog/strkit';

camelCase

str.case.camel

Converts a string to camelCase format. First word is lowercase, subsequent words are capitalized.

Example 
// Namespace API
str.case.camel('hello world');      // 'helloWorld'
str.case.camel('foo-bar-baz');      // 'fooBarBaz'
str.case.camel('FOO_BAR');          // 'fooBar'

// Direct import
import { camelCase } from '@oxog/strkit';
camelCase('hello world');           // 'helloWorld'

// Chainable API
S('hello world').camelCase().value; // 'helloWorld'

kebabCase

str.case.kebab

Converts a string to kebab-case format (lowercase words separated by hyphens).

Example 
str.case.kebab('helloWorld');       // 'hello-world'
str.case.kebab('foo_bar_baz');      // 'foo-bar-baz'
str.case.kebab('Hello World');      // 'hello-world'

// Chainable
S('helloWorld').kebabCase().value;  // 'hello-world'

snakeCase

str.case.snake

Converts a string to snake_case format (lowercase words separated by underscores).

Example 
str.case.snake('helloWorld');       // 'hello_world'
str.case.snake('foo-bar-baz');      // 'foo_bar_baz'
str.case.snake('Hello World');      // 'hello_world'

// Chainable
S('helloWorld').snakeCase().value;  // 'hello_world'

pascalCase

str.case.pascal

Converts a string to PascalCase format. All words are capitalized and joined.

Example 
str.case.pascal('hello world');     // 'HelloWorld'
str.case.pascal('foo-bar-baz');     // 'FooBarBaz'
str.case.pascal('my_component');    // 'MyComponent'

// Chainable
S('hello world').pascalCase().value; // 'HelloWorld'

titleCase

str.case.title

Converts a string to Title Case. First letter of each word is capitalized.

Example 
str.case.title('hello world');      // 'Hello World'
str.case.title('the quick brown fox'); // 'The Quick Brown Fox'
str.case.title('HELLO WORLD');      // 'Hello World'

// Chainable
S('hello world').titleCase().value; // 'Hello World'

upper / lower

Locale Support

Convert to uppercase or lowercase with optional locale support for proper internationalization.

Example 
str.case.upper('hello');            // 'HELLO'
str.case.lower('HELLO');            // 'hello'

// With Turkish locale (special i/I handling)
str.case.upper('istanbul', { locale: 'tr' }); // 'ISTANBUL' (with dotted I)
str.case.lower('ISTANBUL', { locale: 'tr' }); // 'istanbul' (with dotless i)

// Chainable
S('hello').upper().value;           // 'HELLO'
S('HELLO').lower().value;           // 'hello'

constantCase

str.case.constant

Converts to CONSTANT_CASE (also known as screaming snake case). Uppercase with underscores.

Example 
str.case.constant('hello world');   // 'HELLO_WORLD'
str.case.constant('fooBar');        // 'FOO_BAR'
str.case.constant('api-key');       // 'API_KEY'

// Chainable
S('hello world').constantCase().value; // 'HELLO_WORLD'

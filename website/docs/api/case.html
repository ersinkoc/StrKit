Case Conversion

14 methods for transforming string case with locale support.

camelCase

Convert string to camelCase.

str.case.camel('hello world');      // 'helloWorld'
str.case.camel('foo-bar-baz');      // 'fooBarBaz'
str.case.camel('FOO_BAR');          // 'fooBar'

// Direct import
import { camelCase } from '@oxog/strkit';
camelCase('hello world');           // 'helloWorld'

// Chainable
S('hello world').camelCase().value; // 'helloWorld'

kebabCase

Convert string to kebab-case.

str.case.kebab('helloWorld');       // 'hello-world'
str.case.kebab('foo_bar_baz');      // 'foo-bar-baz'

// Chainable
S('helloWorld').kebabCase().value;  // 'hello-world'

snakeCase

Convert string to snake_case.

str.case.snake('helloWorld');       // 'hello_world'
str.case.snake('foo-bar-baz');      // 'foo_bar_baz'

// Chainable
S('helloWorld').snakeCase().value;  // 'hello_world'

pascalCase

Convert string to PascalCase.

str.case.pascal('hello world');     // 'HelloWorld'
str.case.pascal('foo-bar-baz');     // 'FooBarBaz'

// Chainable
S('hello world').pascalCase().value; // 'HelloWorld'

titleCase

Convert string to Title Case.

str.case.title('hello world');      // 'Hello World'
str.case.title('the quick brown fox'); // 'The Quick Brown Fox'

// Chainable
S('hello world').titleCase().value; // 'Hello World'

upper / lower

Convert to uppercase or lowercase with locale support.

str.case.upper('hello');            // 'HELLO'
str.case.lower('HELLO');            // 'hello'

// With Turkish locale
str.case.upper('istanbul', { locale: 'tr' }); // 'İSTANBUL'
str.case.lower('ISTANBUL', { locale: 'tr' }); // 'ıstanbul'

// Chainable
S('hello').upper().value;           // 'HELLO'
S('HELLO').lower().value;           // 'hello'

constantCase

Convert to CONSTANT_CASE (screaming snake case).

str.case.constant('hello world');   // 'HELLO_WORLD'
str.case.constant('fooBar');        // 'FOO_BAR'

// Chainable
S('hello world').constantCase().value; // 'HELLO_WORLD'

Diff

7 methods for text diffing and patching.

Character Diff

str.diff.diffChars('hello', 'hallo');
// [
//   { type: 'equal', value: 'h' },
//   { type: 'remove', value: 'e' },
//   { type: 'add', value: 'a' },
//   { type: 'equal', value: 'llo' }
// ]

Word & Line Diff

str.diff.diffWords('hello world', 'hello there world');
// [
//   { type: 'equal', value: 'hello ' },
//   { type: 'add', value: 'there ' },
//   { type: 'equal', value: 'world' }
// ]

str.diff.diffLines('line1\nline2', 'line1\nline3');
// Line-level diff output

Unified Patch

// Create unified diff patch
const patch = str.diff.createPatch('file.txt', 'old content', 'new content');
// Returns unified diff format string

// Apply patch
const result = str.diff.applyPatch(originalText, patch);

// Reverse patch
const reverted = str.diff.reversePatch(patchedText, patch);

All Methods

diffChars - Character-level diff
diffWords - Word-level diff
diffLines - Line-level diff
diff - Generic diff with options
createPatch - Create unified patch
applyPatch - Apply patch
reversePatch - Reverse a patch

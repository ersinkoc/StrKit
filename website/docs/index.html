Getting Started

Learn how to install and use StrKit in your project. Get up and running in less than 5 minutes.

Zero Dependencies

StrKit has no external dependencies, making it lightweight and reliable.

1 Installation

Install StrKit using your preferred package manager:

Terminal 
npm install @oxog/strkityarn add @oxog/strkitpnpm add @oxog/strkitbun add @oxog/strkit

2 Quick Start

StrKit offers 4 different API styles. Choose the one that fits your coding style:

Recommended Namespace API

Access all methods through organized namespaces for clean, readable code:

TypeScript 
import { str } from '@oxog/strkit';

// Case conversion
str.case.camel('hello world');      // 'helloWorld'
str.case.kebab('helloWorld');       // 'hello-world'

// Validation
str.validate.email('test@example.com');  // true
str.validate.url('https://example.com'); // true

// Similarity
str.similarity.levenshtein('kitten', 'sitting');  // 3

Tree-shakeable Direct Import

Import only what you need for optimal bundle size:

TypeScript 
import { camelCase, isEmail, slugify } from '@oxog/strkit';

camelCase('hello world');   // 'helloWorld'
isEmail('test@test.com');   // true
slugify('Hello World!');    // 'hello-world'

Fluent Chainable API

Fluent, immutable method chaining for complex transformations:

TypeScript 
import { S } from '@oxog/strkit';

const result = S('  Hello World  ')
  .trim()
  .lower()
  .camelCase()
  .truncate(8)
  .value;  // 'helloW...'

// Immutable - original is unchanged
const a = S('hello');
const b = a.upper();
console.log(a.value);  // 'hello'
console.log(b.value);  // 'HELLO'

Opt-in Prototype Extension

Extend native String prototype for the most natural syntax:

TypeScript 
import '@oxog/strkit/extend';

'hello world'.camelCase();    // 'helloWorld'
'test@test.com'.isEmail();   // true
'  hello  '.trim().upper();  // 'HELLO'

Prototype extension modifies global objects. Use with caution in shared libraries.

3 TypeScript Support

StrKit is written in TypeScript with complete type definitions:

TypeScript 
import {
  S,
  str,
  type StrKitChain,
  type DiffResult,
  type AnalysisResult
} from '@oxog/strkit';

const chain: StrKitChain = S('hello');
const result: DiffResult[] = str.diff.diffChars('a', 'b');

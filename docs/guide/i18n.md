# Internationalization (i18n)

StrKit includes built-in support for 14 locales with proper Unicode handling.

## Supported Locales

| Code | Language |
|------|----------|
| `en` | English (default) |
| `tr` | Turkish |
| `de` | German |
| `fr` | French |
| `es` | Spanish |
| `pt` | Portuguese |
| `it` | Italian |
| `nl` | Dutch |
| `pl` | Polish |
| `ru` | Russian |
| `ar` | Arabic |
| `zh` | Chinese |
| `ja` | Japanese |
| `ko` | Korean |

## Setting the Locale

```typescript
import { setLocale, getLocale } from '@oxog/strkit';

// Set global locale
setLocale('tr');

// Get current locale
getLocale();  // 'tr'
```

## Locale-Aware Operations

### Case Conversion

Turkish has special case mapping rules for `i` and `I`:

```typescript
import { str, setLocale } from '@oxog/strkit';

// Default (English)
str.toUpperCase('istanbul');  // 'ISTANBUL'
str.toLowerCase('ISTANBUL');  // 'istanbul'

// Turkish locale
setLocale('tr');
str.toUpperCase('istanbul');  // 'İSTANBUL' (dotted I)
str.toLowerCase('ISTANBUL');  // 'ıstanbul' (dotless i)
```

### Transliteration

Convert non-Latin characters to ASCII equivalents:

```typescript
import { transliterate, latinise } from '@oxog/strkit';

// Basic latinisation (accent removal)
latinise('Héllo Wörld');  // 'Hello World'
latinise('Cześć');        // 'Czesc'

// Locale-specific transliteration
transliterate('Привет', 'ru');  // 'Privet'
transliterate('北京', 'zh');     // 'Beijing' (if mapping exists)
```

### Slugify

Create URL-safe slugs with locale support:

```typescript
import { slugify } from '@oxog/strkit';

slugify('Türkçe İçerik');           // 'turkce-icerik'
slugify('Größe des Hauses');        // 'grosse-des-hauses'
slugify('Héllo Wörld', { locale: 'fr' });  // 'hello-world'
```

### Number Formatting

Different locales use different number formats:

```typescript
import { formatNumber } from '@oxog/strkit';

// English format
formatNumber(1234567.89);  // '1,234,567.89'

// German format
formatNumber(1234567.89, { thousands: '.', decimal: ',' });  // '1.234.567,89'
```

## Custom Locales

Register your own locale:

```typescript
import { registerLocale } from '@oxog/strkit';

registerLocale({
  code: 'custom',
  name: 'Custom Locale',
  case: {
    upper: { 'a': 'Ä' },
    lower: { 'Ä': 'a' },
  },
  plural: {
    rules: [],
    irregulars: {},
    uncountables: [],
  },
  transliterate: {
    'ä': 'ae',
    'ö': 'oe',
  },
  numbers: {
    decimal: ',',
    thousands: '.',
  },
  ordinals: {
    default: '.',
    rules: [],
  },
});
```

## Unicode Support

StrKit properly handles Unicode characters:

```typescript
import { str } from '@oxog/strkit';

// Emoji support
str.reverse('👋🌍');      // '🌍👋'
str.charCount('👨‍👩‍👧‍👦');  // 1 (counts as single grapheme cluster)

// CJK characters
str.charCount('你好');    // 2
str.byteSize('你好');     // 6 (UTF-8 bytes)

// Combining characters
str.charCount('café');   // 4 (composed form)
```
